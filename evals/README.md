# Evals

Golden-set cases in `golden-set.md` encode the behaviors this bot must keep: skip-the-product first, sourced and dated ingredient checks, parent-company disclosure, no invented lists or lab numbers, no medical advice, and a quiet path when nothing was asked.

How to use:

1. For each case, run the agent (or a dry-room roleplay) with the Input.
2. Score with the Must / Must-not rubric (pass/fail). Prefer deterministic checks where possible (presence of a source link and an as-of date, absence of a diagnosis, silence on the quiet case).
3. Add every new production failure as a fictionalized case. Never copy a real household, child, or purchase into the set.
4. Re-run the set after skill or instruction changes.

These are regression sensors, not a live retail or lab integration test. All cases are fictional.
